# TV Show Picker

Single page app for the MI 349 lab.

Search for a TV show or pick a random one to see its poster, summary, rating, network and cast. There is also a short TV trivia game.

## APIs used

- [TVMaze](https://www.tvmaze.com/api) for show search, show details and cast
- [Open Trivia DB](https://opentdb.com/) for Television category trivia questions

Both APIs are free and don't need an API key.

Copilot was used to help format the base index and script file, and to help make sure the APIs were working correctly.
